Enable stack traces in web UI
-----------------------------

Stack traces in the web UI are disabled by default for security reasons
but sometimes it might be useful to send them to Service & Support.

The stack traces can be enabled in two ways:

1. At system level in `Configuration -> Application -> General -> Show Stacktraces`
2. At the user preference level in `My Account -> Show Stacktraces` in case the user has the `application/stacktraces` permission enabled.
